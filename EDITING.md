# Editing Rachel’s website

Open [the website editor](https://rachelsep-4jmyx4hk.sanity.studio/) and sign in
with the Google account that owns the Sanity project.

## Add a model home or commercial space

1. Choose **Model homes** or **Commercial spaces**, then create a project.
2. Enter the project name and introduction.
3. Under **Cover photos**, upload the collection cover and large header photo.
4. Under **Page content**, add text sections and photo galleries. Drag sections
   and photographs to reorder them.
5. Under **Publishing**, generate the page address and set the display order.
   Lower numbers appear earlier. Keep the address unchanged after publishing.
6. Use the **Preview** tab to review the project draft, then **Publish**.

Netlify rebuilds the website after publishing. The change appears when that
deploy finishes, rather than immediately when you press Publish. If a build
fails, the last successfully published website remains available.

## Replace photographs or edit text

- Open an existing project to replace its cover/header photos or edit a gallery.
- Open **Home** to change the slideshow, headline, text, or featured projects.
- Open **About** to edit the biography, portrait, statistics, and selected work.
- Open **Art & curation** or **Hand-drawn artwork** to manage those galleries.
- Open any page’s **Page text** list, select a text field, and edit its value.
- Open **Site settings** to change logo words, menu labels, and footer text.

Image descriptions help visitors using screen readers. Uploaded images can be
reused through the image selector. Draft changes stay in the editor until
published. The project Preview tab shows unpublished project content; the
other pages do not currently have a live draft Preview tab.

## Hide a project

Turn on **Hide this project**, then publish. The next successful build removes
it from its collection, featured sections, and its public page. Turn the option
off and publish to bring it back. The photos remain stored in Sanity.

## Publishing status

[Netlify deploys](https://app.netlify.com/projects/teal-kitsune-82a899/deploys)
shows whether the latest update is building, published, or failed. The website
code is stored in [GitHub](https://github.com/Cameronglass/RachelSep).

If you edit content, use Sanity. Changes to layouts or new functionality still
require development work in the repository.
